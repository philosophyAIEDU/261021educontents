# /start — 시작 안내와 현황

작업 폴더: 이 프로젝트 폴더. 사용자는 **교수·교육자**다. 한국어 존댓말로, 개발 용어 없이, **한 번에 한 단계만** 안내한다.

## 1. 상태 확인 (질문하기 전에 직접 본다)

먼저 `node scripts/setup-check.mjs`를 실행한다. 아래 표의 항목을 순서대로 점검해 ✅/⬜와 "다음 할 일"을 알려 준다 (`.env`·`keys/`는 존재와 파일 이름만 본다). 세션 시작 때 같은 결과가 자동으로 맥락에 들어와 있으면 그것을 써도 된다. Node.js가 없어 실행이 안 되면 1단계(Node.js 설치)부터 안내한다.

세팅은 두 갈래다. **먼저 "자료 넣고 초고 받기"(4단계)를 끝내** 교수님이 결과물을 바로 보게 하고, 관리자 페이지(Firebase)는 그다음에 권한다. Firebase 없이도 `/make`는 돌아간다 (초고는 `drafts/`에 생긴다).

| 갈래 | 확인 | 방법 |
|---|---|---|
| 초고 | 프로필 | `profile.md`의 `이름`·`전공 분야`가 비었는가 |
| 초고 | 자료 | `processed/*.json` 개수, `raw/`에 처리 전 파일 |
| 초고 | 첫 초고 | `drafts/` 아래 초고, 처리 전 자료가 남았는가 |
| 관리자 페이지 | 설치 | `scripts/node_modules` 폴더가 있는가 |
| 관리자 페이지 | Firebase | `.env` 파일이 **있는지만** 본다 (내용은 읽지 않는다), `keys/`의 `.json` **파일 이름만** 본다 |
| 관리자 페이지 | 페이지 설정 | `admin/index.html`의 `firebaseConfig`에 `YOUR_`가 남았는가 |
| 관리자 페이지 | 보는 곳 | `내 사이트`면 `site-repo/`에 `knowledge-admin.html`이 들어갔는가, `내 컴퓨터`면 위와 같다 |

## 2. 단계별 안내 (지금 단계 하나만)

0. **처음 인사**: 사용자가 처음 묻는 것이면 "이 폴더는 교수님이 가진 자료(슬라이드, 한글·워드 문서, PDF, 강의 녹취)를 넣으시면 정리해서 강의안·학습자료·평가문항·칼럼 초안을 자동으로 뽑아 드립니다. 이름과 전공만 알려 주시고 raw 폴더에 자료를 넣은 뒤 `/make`라고 하시면 됩니다"처럼 한두 줄로 시작한다.
1. **프로필**: 이름과 전공 분야만 묻는다. 나머지 프로필(아래 "3. 프로필 질문")은 첫 초고가 나온 뒤에 천천히 채운다.
2. **자료 넣기**: `raw/` 폴더 위치를 알려 주고 파일을 넣게 한다 (탐색기·Finder로 끌어다 놓기). 처음이면 `examples/`의 연습 강의를 `raw/`로 복사해 준다. 한 과목의 연속된 차시 3~5편이 가장 좋다고 알린다.
3. **첫 초고**: `/make`를 실행한다. 끝나면 초고 파일 위치와 교수님이 확인할 것을 알려 준다.
4. **설치** (관리자 페이지를 원할 때부터): 내가 대신 실행한다: `npm install --prefix scripts`.
5. **Firebase 만들기**: 사용자가 **직접** 해야 한다. `TUTORIAL.md` 3~4단계를 한 화면씩 안내하고, 지금 화면에 무엇이 보이는지 물어본다. `.env`는 내가 `.env.example`을 복사해 만들어 줄 수 있지만 **값은 사용자가 직접** 채운다. 학교 구글 계정(Google Workspace)은 관리자가 Firebase를 막아 두었을 수 있으니, 막히면 개인 구글 계정을 권한다.
   `.env`가 생기면 로컬에만 있던 자료와 초고를 올린다: `node --env-file=.env scripts/upload.mjs --all --commit`(미리 검사 먼저, 확인 후), 초고는 `/draft save <경로>`.
6. **관리자 페이지 설정**: Firebase 콘솔의 웹 앱 설정(`firebaseConfig`)을 붙여 달라고 한다 (이 값은 공개돼도 되는 값이다). 받은 값과 profile.md의 `이름`을 `admin/index.html`의 `SITE_NAME`, `firebaseConfig`에 넣는다.
7. **보는 곳**: `내 사이트`면 `/site`를 권한다. `내 컴퓨터`면 `npx serve admin`을 대신 실행하고 `http://localhost:3000`을 열어 Google 로그인해 보게 한다.

첫 초고가 나온 뒤 권할 것: `/make`가 처음 만든 `voice.md`·`knowledge-map.md` 초안 읽고 고치기, 학생 질문(`/ingest-questions`), 여러 자료를 묶는 결과물(`/asset-ideas` → `/draft`), 매주 예약 실행(`/auto`, `/menu` 참고).

## 3. 프로필 질문 (profile.md 채우기)

**한 번에 한두 가지씩** 묻는다. 답을 받을 때마다 `profile.md`의 해당 줄(`- 항목: 값`)에 적고, 다 채우면 맨 위 "상태" 줄을 `채움 (YYYY-MM-DD)`로 바꾼다. 항목 이름은 바꾸지 않는다 (스크립트가 읽는다).

1. 이름(관리자 페이지와 결과물에 쓸 표기)과 소속
2. 전공 분야와 세부 연구 주제
3. 담당 과목(과목명과 대상 학년)과 주요 학습자(학부생, 대학원생, 현직 교사, 일반 시민 등)
4. 지식을 펼치는 채널 (수업 / 유튜브 / 칼럼 / 블로그 / 뉴스레터 / 책) → `운영 채널`, 가장 자주 만들 결과물 → `기본 결과물 종류` (강의안 / 학습자료 / 평가문항 / 칼럼 / 블로그 / 영상대본 / 교재)
5. 관리자 페이지를 **내 사이트**에 올릴지, **내 컴퓨터**에서만 볼지 → `관리자 페이지 보는 곳`. 사이트면 **사이트 주소**와 **그 사이트의 GitHub 저장소 주소**
6. 유튜브 채널 주소(`https://www.youtube.com/@핸들`), 블로그·뉴스레터 RSS 주소, 사이트 말고 내 글이 올라가는 곳(`내 다른 주소`: 브런치, 학교 교수 소개 페이지, 언론사 칼럼 기사 주소) — 없으면 비운다. RSS 주소를 모르면 사이트 주소 뒤에 `/rss.xml`, `/feed`, `/rss`를 붙여 열어 보고 제안한다.

함께 반영할 것:
- 전공 분야·세부 주제·학습자는 `.claude/skills/taxonomy/taxonomy.md`에 "교수님 설명(아직 확정 전)"으로 적는다. `/ingest`가 태그를 고를 때 쓴다.
- 담당 과목은 `/knowledge-map` 7절(자산 공백)의 기준이 된다.
- 말투는 **직접 정하지 않는다.** `/analyze-style`이 실제 자료에서 뽑는다. 교수님이 "이 말은 절대 안 써요"라고 하면 `voice.md` 금칙어 절에 추가한다.
- 반응 등급은 선택이다. 유튜브 강의가 있으면 조회수 기본 기준(100 / 1000)을 보여 주고 바꿀지 묻는다. 강의평가 점수 등으로 등급을 매기고 싶어 하면 기준("몇 점 이상이 상인가요?")을 받아 `CLAUDE.md`의 반응 등급 문단에 적는다.

## 4. 현황 (자료가 1편 이상일 때 함께 보여 준다)
- `raw/`(하위 `questions/` 포함, `hold/` 제외)에서 아직 `processed/`에 없는 파일 → "아직 안 올린 파일" (문서 파일은 `.meta.json`의 `original_file`로 변환 여부를 본다)
- `raw/hold/`의 파일과 `.hold.txt` 사유 → "보류된 파일"
- `processed/*.json` 표: id, 제목, 종류, 분야, 지식 유형, 학습자, 강의·작성일, 비어 있는 태그
- 집계: 종류별·분야별·지식 유형별 편수, `drafts/`의 초고 수
- 수치는 파일 값을 그대로 옮기고 추정하지 않는다. 실제 Firebase 내용은 관리자 페이지에서 확인하라고 안내한다.

## 보고
확인 결과 한두 줄 → 다음 할 일 **하나** (사용자가 할 일인지, 내가 대신 할 수 있는 일인지 구분) → 필요하면 현황 표. 긴 목록을 한꺼번에 쏟아내지 않는다.

## 금지
- `.env`, `keys/`의 내용을 읽거나 출력하지 않는다. 사용자가 키나 `.env` 내용을 채팅에 붙이려 하면 말린다. 이미 붙였다면 그 키를 폐기하고 새로 발급하도록 안내한다.
- profile.md에 비밀번호·API 키·서비스 계정 키·학생 정보를 적지 않는다.
