# 녹취 용어집 (오인식 → 올바른 표기)

교수님 확인을 받아 확정한 것만 적는다. `주의`는 오탐 방지용이다. 자동 자막·녹음 전사에서 자주 틀리는 전공 용어, 학자 이름, 이론명, 과목명을 하나씩 추가한다.

| 오인식 | 올바른 표기 | 주의 |
|---|---|---|
| (예) 메타 인지 | 메타인지 | 조사는 그대로 유지 |
| (예) 피아 제 | 피아제 | 사람 이름. 문맥이 학자일 때만 |
| 줄 맨 앞의 `>> ` | (삭제) | 화자 전환 표시 |

## 확정하지 못한 표기 (교수님 확인 필요)
