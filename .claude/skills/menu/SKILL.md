# /menu — 명령어 메뉴 (읽기 전용)

## 절차
1. `.claude/skills/*/SKILL.md`의 `name`을 읽어 실제 목록과 아래 표를 비교한다. 표에 없는 스킬은 맨 아래 "기타"로 덧붙여 보여 주고, 없어진 스킬은 "(현재 없음)"으로 표시한다. 어긋나면 이 파일을 고칠지 물어본다 (묻기 전에는 고치지 않는다).
2. 아래 세 표를 보여 준다. 특정 명령을 물으면 그 `SKILL.md`를 읽어 쉽게 설명한다.

## 기본 명령 (이것만 알면 된다)

흐름: **모으기(Input) → 분석 → 아이디어 → 초고(Output)**, 결과는 내 사이트의 관리자 페이지에서 본다.

| 명령어 | 하는 일 | 예시 |
|---|---|---|
| `/start` | 지금 몇 단계인지 보고 다음 할 일 하나를 알려 준다. 브랜드 정보(사이트 주소 등)를 채운다 | `/start` |
| `/site` | 관리자 페이지를 내 사이트에 올린다 (`내 사이트/contents-admin.html`) | `/site` |
| `/ingest` | 내 콘텐츠를 가져와 정리·태깅하고 **Contents Input**에 올린다 | `/ingest https://youtu.be/...` `/ingest 내 블로그 글 가져와` |
| `/analyze-style` | 올린 콘텐츠로 내 말투(`voice.md`)와 잘 된 패턴(`structure.md`)을 채운다 (처음 한 번) | `/analyze-style` |
| `/topic-ideas` | 다음 주제 후보 5개를 근거와 함께 제안한다 | `/topic-ideas` |
| `/draft` | 주제 한 줄로 초고를 쓰고, 검수한 뒤 **Contents Output**에 자동 저장한다 | `/draft 스레드 주제 한 줄` `/draft 뉴스레터 script-04` |
| `/auto` | 위 과정을 질문 없이 한 번에: 새 콘텐츠 가져오기 → 올리기 → 주제 → 초고 3개 → Output | `/auto` (매주 예약 실행 가능) |

## 가끔 쓰는 명령

| 명령어 | 하는 일 | 언제 |
|---|---|---|
| `/feedback` | 조회수·성과등급 갱신, 발행 후 수정 정도와 성과 기록 | 조회수가 바뀌었을 때, 발행 7~14일 뒤 |
| `/monthly-review` | 지난달 상·하위를 비교해 `voice.md`·`structure.md` 수정안을 만들고, 승인한 것만 반영 | 매월 초 |
| `/draft save <파일>` | 손질한 초고를 Output에 다시 올린다 | 초고를 고친 뒤 |
| `/audit` | 키 유출·개인정보·타인 콘텐츠 점검 (읽기 전용) | GitHub에 올리기 전 |
| `/takedown` | 잘못 올린 콘텐츠를 Firebase에서 삭제 (확인 후) | 실수로 올렸을 때 |

## 익숙해지면 쓰는 명령

| 명령어 | 하는 일 |
|---|---|
| `/ingest-comments` | 댓글에서 작성자 정보를 지우고 반응 유형(질문·요청 등)으로 분류해 올린다 |
| `/fix-transcript` | 자동 자막의 제품명·고유명사 오인식을 용어집 기준으로 고친다 |
| `/taxonomy` | 카테고리·타깃 태그 표기를 통일한다 |

## 자동으로 도는 검수 (직접 부를 필요 없음)

| 검수 | 하는 일 |
|---|---|
| `data-checker` | 올리기 직전: 필수 태그, 중복, 개인정보 |
| `voice-checker` | 초고 직후: 내 말투인지, 금칙어 |
| `risk-checker` | 초고 직후: 과장·성과 약속, 개인 노출, 근거 없는 수치 |

## 주간 루틴 (예시)

| 시점 | 할 일 |
|---|---|
| 매주 월요일 | `/auto` (예약 실행해 두면 자동) → 관리자 페이지 Output에서 초고 확인 → 20% 손질해서 발행 |
| 발행 7~14일 뒤 | `/feedback` |
| 매월 초 | `/monthly-review` |
| 헷갈릴 때 | `/start` |

예약 실행 방법은 `.claude/skills/auto/SKILL.md`의 "예약 실행"을 요약해 알려 준다. 자동 실행은 `voice.md`·`structure.md`를 절대 바꾸지 않는다.
