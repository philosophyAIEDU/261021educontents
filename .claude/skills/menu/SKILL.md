# /menu — 이렇게 말하세요 (읽기 전용)

## 절차
1. `.claude/skills/*/SKILL.md`의 `name`을 읽어 `CLAUDE.md`의 "교수님께는 명령어 대신 자연어로" 표와 비교한다. 표에 없는 스킬이 있으면 끝에 쉬운 말로 덧붙이고, 어긋나면 이 표를 고칠지 물어본다 (묻기 전에는 고치지 않는다).
2. `PROMPTS.md`를 읽어 지금 교수님 단계에 맞는 표 한두 개를 보여 주고, 전체는 `PROMPTS.md`에 있으며 똑같이 쓰지 않아도 된다고 알린다. 슬래시 명령은 교수님이 물을 때만 알려 준다.
3. 특정 기능을 물으면 그 `SKILL.md`를 읽어 쉽게 설명하고, 입력할 문장을 함께 알려 준다.

## 흐름
사이트와 Firebase는 이미 있다고 본다: **연결 → Input에 모으기(지식 창고) → 분석·지식 지도 → Output에 쌓기(결과물) → 공개할 글은 관리자 페이지에서 "사이트에 게시"**.

## 자동으로 도는 검수 (부를 필요 없음)

| 검수 | 하는 일 |
|---|---|
| `data-checker` | 올리기 직전: 필수 태그, 중복, 학생 신원 정보, 저작권 의심 |
| `voice-checker` | 초고 직후: 교수님 말투인지, 금칙어 |
| `risk-checker` | 초고 직후: 지어낸 인용·근거 없는 연구 결과, 평가문항 정답 근거, 효과 약속, 학생 노출 |

## 학기 루틴 (예시)

| 시점 | 이렇게 말하세요 |
|---|---|
| 처음 한 번 | "시작해 주세요" |
| 학기 시작 전 | "새 자료를 지식 지도에 반영해 주세요", "다음에 뭘 만들면 좋을지 추천해 주세요" |
| 매주 수업 후 | 슬라이드·녹취를 `raw/`에 넣고 "자료 넣었어요. 초고 만들어 주세요." |
| 학생 질문이 모이면 | "학생 질문 정리해 주세요" |
| 수업·발행 후 | "이 강의안으로 수업했어요" |
| 매월 초, 학기 말 | "이번 달을 돌아봐 주세요", "이번 학기를 정리해 주세요" |
| 헷갈릴 때 | "다음은 뭐 해요?" |

예약 실행 방법은 `.claude/skills/auto/SKILL.md`의 "예약 실행"을 요약해 알려 준다. 자동 실행은 `voice.md`·`structure.md`·`knowledge-map.md`를 절대 바꾸지 않는다.
