# /auto — 모으기부터 초고까지 자동 실행 (질문 없음)

작업 폴더: 이 프로젝트 폴더. **사용자에게 질문하지 않는다.** 아무도 보지 않을 때 예약 실행되므로, 질문하면 거기서 멈춘다. 문제가 생기면 기록하고 가능한 데까지 진행한다.

## 범위
- `/auto` : 1 → 2 → 3 → 4 → 5
- `/auto 수집만` : 1 → 2 → 5
- `/auto 초고만` : 3 → 4 → 5

## 절차
0. **준비**: `date +%Y-%m-%d`, `date +%H%M`으로 날짜·시각을 얻고 `CLAUDE.md`, `brand.md`를 읽는다. `.env`가 없으면(존재만 확인) 업로드·Output 저장은 건너뛰고 그 사실을 기록한다.

1. **새 콘텐츠 가져오기**
   - brand.md의 `사이트 저장소 폴더`(기본 `site-repo`)가 있으면 `git -C site-repo pull`로 최신화한다 (실패해도 계속).
   - `node scripts/extract.mjs --auto --limit 5` — 유튜브 채널·RSS·사이트 저장소 중 brand.md에 적힌 곳에서 **새로 나온 것만** `raw/`에 가져온다.
   - 가져올 곳이 하나도 없으면 "brand.md에 가져올 곳이 없음"을 기록하고, `raw/`에 사용자가 넣어 둔 파일만 처리한다.

2. **정리·업로드**: `.claude/skills/ingest/SKILL.md`의 **자동 모드**를 그대로 수행한다 (애매한 것은 `raw/hold/`로 보류, 검수 통과한 것만 업로드).

3. **주제 후보 5개**: `.claude/skills/topic-ideas/SKILL.md`의 절차 2~6을 그대로 수행한다.
   - `voice.md`나 `structure.md`가 "빈 템플릿"이면 3~4를 건너뛰고 "먼저 `/analyze-style`이 필요함"을 기록한다. **자동 실행은 이 파일들을 채우거나 고치지 않는다.**

4. **초고 3개**: 후보 표 1~3번 주제로 초고를 쓴다.
   - 채널: brand.md의 `기본 초고 채널` (비어 있으면 스레드). 후보의 추천 채널이 `운영 채널`에 있으면 그 채널을 써도 된다.
   - `.claude/skills/draft/SKILL.md`의 채널 규칙을 따르되 스레드도 **버전 하나만** (근거가 가장 강한 훅 유형).
   - 저장: `drafts/weekly/<날짜>/01_<슬러그>.md`, `02_...`, `03_...` (`draft/review.md` 3의 형식). 같은 날짜 폴더가 있으면 `<날짜>-<HHMM>`으로 새 폴더를 만든다 (덮어쓰지 않는다).
   - 검수: 초고마다 `voice-checker`, `risk-checker`를 부른다 (한 번에 6개 동시 호출 가능). `draft/review.md` 4의 수정·메모 규칙을 따른다. 에이전트가 실패하면 `검수 실패: 이유`를 적고 다음으로 간다.
   - Output 저장: 초고마다 `draft/review.md` 5를 수행한다 (검수 미해결이면 스크립트가 거부하고, 그대로 기록한다).

5. **기록과 보고**: `reports/auto.md` **맨 위**(제목 줄 바로 아래)에 이번 실행을 추가한다. 파일이 없으면 `# 자동 실행 기록 (최신이 맨 위)`로 만든다.
```
## YYYY-MM-DD HH:MM /auto
- 가져오기: 새 콘텐츠 N개 (유튜브 N, RSS N, 사이트 저장소 N)
- 업로드: 성공 N · 보류 N · 실패 N (자세한 내용: reports/ingest-log.md)
- 데이터 한계: (예: 댓글 데이터 없음, 표본 6편)
### 주제 후보 5개
1. ... (근거)
### 초고
| # | 주제 | 채널 | 파일 | voice | risk | Output | 먼저 볼 곳 |
|---|---|---|---|---|---|---|---|
### 사람이 할 일
- (보류 파일 확인, 초고 20% 손질 후 발행, /analyze-style 필요 등. 없으면 "없음")
### 실패·건너뜀
- (없으면 "없음")
```
   채팅에는 위 요약을 짧게 보여 주고 "관리자 페이지 Contents Output 탭에서 초고를 확인하세요"로 끝낸다. 질문으로 끝내지 않는다.

## 금지
- `voice.md`, `structure.md`를 수정하지 않는다. 규칙 개선은 `/monthly-review`에서 사용자가 승인한다.
- 초고를 발행(SNS·뉴스레터·사이트 게시)하지 않는다. 발행은 언제나 사용자가 한다. Output 저장은 관리자 전용 보관이다.
- 삭제(`/takedown`), 사이트 저장소 푸시, `--allow-missing`, `--allow-unresolved`를 하지 않는다.
- `.env`, `keys/`의 내용을 읽지 않는다. 근거 없는 수치를 쓰지 않는다 (규칙 5).

## 예약 실행 (사용자에게 안내할 때)
- **Claude Code 데스크톱 앱**: 예약 작업(Scheduled tasks)에 이 프로젝트 폴더와 프롬프트 `/auto`를 등록하고 요일·시간을 정한다 (예: 매주 월요일 오전 8시). 컴퓨터가 켜져 있어야 한다.
- **터미널**: 프로젝트 폴더에서 `claude -p "/auto" --permission-mode acceptEdits`. 이것을 Windows 작업 스케줄러나 Mac/Linux `cron`에 등록한다. 필요한 명령 권한은 `.claude/settings.json`에 미리 허용돼 있다.
- 처음에는 예약하지 말고 `/auto`를 직접 두세 번 실행해 결과를 확인한 뒤 등록하기를 권한다.
