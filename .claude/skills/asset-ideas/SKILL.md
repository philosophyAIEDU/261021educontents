# /asset-ideas — 다음에 만들 결과물 후보 5개

작업 폴더: 이 프로젝트 폴더. **입력은 필요 없다.** 사용자에게 질문하지 않고 끝까지 진행한다 .

## 절차
1. `CLAUDE.md`의 "결과물 작성" 규칙 4~6, `knowledge-map.md`(특히 5·7·8절), `structure.md`(2·6·9절), `voice.md`, `profile.md`(담당 과목, 운영 채널, 기본 결과물 종류)를 읽는다. `voice.md`·`structure.md`·`knowledge-map.md` 중 하나라도 빈 템플릿이면 멈추고 무엇이 먼저인지(`/analyze-style`, `/knowledge-map`) 알린다.
2. **근거 데이터**를 모은다.
   - `processed/*.json`의 태그·`key_message`와 지식 지도 8절(재활용 지도)로 **아직 다른 형태로 만들지 않은 자료**를 찾는다.
   - 반응 수치·등급이 있으면 반응이 좋았던 자료를 파악한다. 없으면 "반응 데이터 없음"이라고 적는다.
   - **학생 질문**: 지식 지도 5절과 `format: 학생 질문` 문서의 `question_type`이 `오개념`·`개념 질문`·`요청`인 것을 주제별로 묶어 **몇 건인지만** 센다. 원문은 인용하지 않는다 (규칙 4). 없으면 "학생 질문 데이터 없음"이라고 명시한다.
   - `drafts/`(`weekly/` 포함)와 `reports/asset-ideas.md`의 최근 후보를 확인해 **이미 만든 것이나 최근에 제안한 것은 피한다.**
3. **후보 5개**를 만든다. 구성 원칙:
   - 1개 이상은 **학생들이 자주 묻거나 틀린 개념**을 다루는 학습자료·평가문항 (질문 데이터가 있을 때)
   - 1개 이상은 **여러 자료를 묶는 것** (예: 3~5주차 강의 → 교재 한 장, 논문 2편 → 대중 칼럼)
   - 1개는 **하나의 자료를 다른 학습자에게 맞게 다시 쓰는 것** (예: 대학원 세미나 → 현직 교사 연수 강의안, 논문 → 학부생 학습자료)
   - 자산 공백(지식 지도 7절)이 있으면 1개는 "공백을 채우기 위해 교수님이 녹음·정리해 둘 것"을 제안할 수 있다 (이것은 초고 대신 **질문 목록**을 만드는 결과물이다: 종류 `학습자료`, 주제 "<영역> 녹음 전 질문지")
   - `profile.md`의 `운영 채널`과 담당 과목 안에서 종류가 겹치지 않게 분산한다
   - 주제는 **한 줄**로, 그대로 `/draft <종류> <주제>`에 넣을 수 있게 쓴다. 다른 자료를 다시 쓰는 것이면 `/draft <종류> <id>` 형태로 쓴다
4. 출력 형식(한글 표):

| # | 주제(한 줄) 또는 원본 id | 종류 | 근거 | 대상 학습자 | 쓸 곳 |
|---|---|---|---|---|---|
| 1 | 익숙함과 이해를 구분하는 법 — 오개념 바로잡기 | 학습자료 | 학생 질문 '오개념' 4건 (지식 지도 5절), lecture-01 | 학부생 | 교육심리학 4주차 |

   - **근거는 데이터 출처를 적는다** (어떤 자료 id, 질문 N건, 지식 지도 몇 절). 근거가 약하면 "근거 약함"이라고 쓴다.
   - 외부 트렌드·검색량·학계 동향은 조회할 수 없으므로 아는 척하지 않는다.
5. 표 위에 **데이터 한계**를 한 줄로 적는다 (예: "학생 질문 데이터 없음, 반응 데이터 없음, 자료 6편").
6. `reports/asset-ideas.md` **맨 위**에 오늘 날짜 제목(`## YYYY-MM-DD`)으로 같은 내용을 추가한다. 파일이 없으면 `# 결과물 후보 기록 (최신이 맨 위)` 제목으로 만든다.
7. 채팅에는 표와 한계만 보여 준다.

## 금지
- 효과를 약속하는 표현(예: "학생 성적이 오를 주제")을 쓰지 않는다. "질문이 많았던 개념"처럼 사실만 쓴다.
- `voice.md`, `structure.md`, `knowledge-map.md`를 수정하지 않는다.
